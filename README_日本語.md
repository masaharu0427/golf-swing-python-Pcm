# ゴルフスイング分析・Python簡単操作版

最初に提供されたPython / Streamlitアプリを基に作り直した版です。
処理の本体はPython側で動きます。線のドラッグ表示だけ、app.pyに内蔵した小さな画面部品を使います。
「肩・肩・骨盤を順番にクリックする」設定モードはありません。

## Windowsで使う

1. ZIPを右クリックし「すべて展開」します。ZIP内で直接実行しないでください。
2. 64ビット（x64）のPython 3.11または3.12を用意してください。
3. 展開先の `start_windows.bat` をダブルクリックします。
4. 初回は必要なパッケージをインストールします。完了するとブラウザが開きます。
5. 使用中は黒いコマンド画面を閉じないでください。終了はその画面で Ctrl+C です。

既にPython環境がある場合は、展開先で次のコマンドでも起動できます。

```text
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

必要なライブラリはバージョンを指定しています。初回のインストールとAIモデル取得にはインターネット接続が必要です。

## 既存のStreamlit版を更新する

リポジトリの `app.py` と `requirements.txt` を、このZIPの同名ファイルへ差し替えます。
Linux / Streamlit Community Cloudでは `packages.txt` も同じ階層へ置いてください。
Pythonは3.11または3.12を選びます。既存の他機能を含むリポジトリでは元ファイルの控えを取ってください。
同梱の `.streamlit/config.toml` は200MBのアップロード上限と緑系の画面設定です。
このファイル一式を作成しただけで、既存の公開URLやGitHubは変更していません。

## 操作は3つの画面内ステップ

### 1. 動画を選ぶ

- 「動画を選択」で動画を選びます。
- ファイル名と「受信済み」が表示されたら「動画を読み込んで解析」を押します。
- 変換 → AIモデル準備 → 骨格解析の順に進み、進捗を表示します。
- 元と同じMediaPipe Pose Landmarker Heavyを使用します。AI解析はPython側のCPUで実行します。
- 動画は1回のスイング・60秒以内を対象にしています。

### 2. コマと線を調整する

- 「ポジション」でP1〜P10を選びます。
- プレビューのすぐ上の1行にある「◀ 前」、スライダー、「次 ▶」で目的のコマへ合わせます。変更は自動反映します。
- 描画ツールと説明文は画像の下へまとめ、スライダーと画像の間隔を詰めています。
- 角度の文字は従来より約2割小さく表示します。プレビュー・静止画・動画へ共通で反映します。
- 「調整する線」で選んだ線の丸を、映像上で直接ドラッグします。
- その右隣の「線の色」「線の太さ」で、選んだ線ごとに変更できます。プレビューと保存する画像・動画に反映します。
- シャフトプレーンの角度は、ヘッド側とグリップ側の中間より少し下へ表示します。
- 点線は短い線と間隔を細かくしました。肩ラインの角度は、画面右側の端から少し離して表示します。
- 「両肩ラインを表示するP（複数選択）」で対象のPを選べます。未選択なら全コマ、選択時はそのPのコマだけに表示します。
- 後方撮影では、P1の胸と腰の中心線を白点線・太さ2で全コマに固定表示します。動きに追従する通常の胸腰線も同時に表示できます。P1のコマや胸腰線を修正すると、固定線も更新します。正面撮影では固定線を表示しません。
- シャフトは水色がヘッド側、黄色がグリップ側です。丸で角度を変え、線をつかむと全体を移動できます。
- ヒップはオレンジの丸、または縦線を左右へ動かします。
- 正面の「胸と腰の傾き」は垂直＝0°、目標側を正、反対側をマイナスの整数で表示します。左側の管理線設定で「目標方向（画面上）」を選んでください。
- 傾きラインと一緒に、現在の腰中心を通る垂直の白点線（太さ2）を表示します。
- 頭の円は、P1の位置を点線で固定し、もう1つの円が各コマの頭に追従します。同じ大きさで位置のずれを比較できます。
- 頭の丸をドラッグすると、P1の基準位置と円の大きさを調整できます。骨格を検出できないコマは追従円を表示せず、基準円を残します。
- 胸腰・肩の手動修正は各Pのコマへ保存します。
- 肩の両端を動かすと、その中点へ胸腰線がつながるようにします。
- 元動画の実際のクラブをAIが検出しているわけではないため、シャフトの初期位置は必ずクラブに合わせてください。
- 「直線」「円」「手描き」は、映像上をドラッグして追加します。「戻す」で取り消せます。
- 「このPのみ」にチェックすると、そのP専用の図形になります。チェックを外すと共通図形です。
- 線の表示切替・正面／後方プリセットは、左上の「≫」から管理線設定を開いて変更できます。
- 点線・表示するPは「点線・表示するPを変更」で設定します。
  表示Pが未選択なら全コマ、選択済みなら指定したPのコマにだけ表示します。

### 3. 作成して保存する

- 動画で止めるP、静止画にするPをそれぞれ選びます。線の表示Pを選ぶ操作とは別です。
- 停止予定のP・コマ番号・元動画での秒数を確認できます。同じコマに複数のPがある場合も、各P名を表示して順番に停止します。別の瞬間にしたい場合はコマ調整で分けてください。
- 停止時間は0.5秒以上です。停止対象やコマを変えた後は分析動画を作り直してください。
- 「分析動画を作成」または「選択した静止画を作成」を押します。
- 作成後に現れる保存ボタンで、MP4、PNG、連続写真、ZIPを保存します。
- 動画はH.264のMP4・音声なしで書き出します。元のフレームに指定秒数の静止時間を追加します。

## 基準棒で腰の移動量を測る（cm）

1. カメラを三脚などで固定します。正面または後方から撮影し、腰と同じ奥行きに基準棒を置きます。棒は映像の奥行き方向に傾けず、両端がはっきり見えるようにしてください。棒は同じ動画の1コマに映れば使えます。
2. 「AI骨格解析を行う」を有効にして動画を読み込み、P1をアドレスのコマに合わせます。
3. プレビュー下の「基準棒で腰の移動量を測る（cm）」を開き、基準棒の実際の長さをcmで入力します。P1で両端が見えない場合は「棒の両端が見えるコマ」を変更します。
4. 基準棒の片端と反対側の端を、映像上で順番にクリックします。指定し直すときは、もう一度片端をクリックして始めます。
5. P1を0.0 cmとして、P1〜P10の腰の中心の移動量を表示します。画面の右・上がプラス、左・下がマイナスです。腰を検出できないコマは「—」で表示します。

同じ動画内では撮影中のズームやカメラの移動を避けてください。値は映像上の左右・上下を換算した推定値です。腰がカメラに近づいたり遠ざかったりすると、遠近の影響を受けます。数値はアプリの測定欄で確認できます。

## 元のコードからの主な変更

- 全コマ画像をRAMへ保存せず、解析は逐次処理し、プレビューは必要な1コマだけ読みます。
- 30fps・長辺960px（設定で720px）へ変換してから解析します。高速度撮影の元データはそのまま残してください。
- スマホの縦撮影の向き、読み取れない形式、変換失敗を確認し、理由を画面に出します。
- URLのクエリ文字列へ線の座標を書き込む方法をやめ、Streamlitの双方向部品からPythonへ変更を渡します。
- 動画作成失敗時に、再生互換性の低い未変換MP4へすり替える処理は行いません。
- 出力ファイルをセッションごとの作業フォルダに分け、別の利用者のデータと混ざらないようにします。

## 留意点と動作確認

- 自動P推定は、元のコードと同様、手首の軌跡などを使う簡易候補です。特にP7は映像で確認してください。
- 骨格が検出できないコマでは、身体に合っていない架空の肩・胸腰線は出しません。別のコマか手描き線を使ってください。
- シャフト・ヒップは手動調整用の線なので、骨格解析ができなくても表示・操作できます。
- コマや線を変更すると、既に作成した出力は無効になり、再作成が必要です。
- ブラウザを更新・閉じると編集中の状態は失われる場合があります。完成物は保存ボタンでダウンロードしてください。
- Androidの写真選択画面の「動画を準備しています」は端末側の処理です。この待ち時間がPython変更だけで必ず解消するとは限りません。
- Linux / Python3.12で、実動画の変換、HeavyモデルのCPU解析（試験動画45コマ中45コマ検出）、MP4書き出し、静止画ZIP、P選択、線の変更のPythonへの反映を確認しました。
- 自動テスト10件が成功しています。ブラウザ上でシャフトのドラッグ後に角度が変わり、コマ変更後も線が保持されることを確認しました。
- Windowsの起動バッチとAndroid実機では未検証です。
